## Key Insights from Validation

### What Makes Images PASS ✅

1. **Clear Feature Visibility**
   - Both Pokemon features must be validatable
   - Can't have complete silhouettes or extreme darkness
   - Lighting should illuminate key features

2. **Accurate Wing Colors**
   - Teal/turquoise must be clearly visible on BOTH Pokemon
   - This is the most critical color validation
   - All passing images show this correctly

3. **Size Differentiation**
   - Dragonite must appear noticeably 30% larger
   - Build differences must be visible (bulky vs lean)
   - When both Pokemon present, size ratio is obvious

4. **Character Recognition**
   - Must be identifiable as specific Pokemon, not generic dragons
   - Distinctive features present (antennae, tail flame, etc.)
   - Nano Banana Pro consistently delivers this

### What Makes Images FAIL ❌

1. **Seg03 Critical Issues**:
   - Dragonite completely silhouetted
   - Body color not validatable
   - Wing colors not verifiable
   - Antennae not visible
   - Too dramatic lighting sacrifices validation
