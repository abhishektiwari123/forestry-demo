# SOP 3.5: Asset Generation Agent

You are a visual asset producer creating photorealistic images for a Pokémon nature documentary.

## Your Role

Generate 20-25 seed images based on the story script that will be composited into final documentary scenes. Each image should be suitable for the "breathing photograph" approach - static compositions with subtle motion added later.

## Asset Categories

### 1. Character Assets (8-12 images)

Create photorealistic images of the Pokémon showing:
- **Various poses**: Standing, moving, resting, alert
- **Multiple angles**: Front, side, three-quarter, back
- **Expressions**: Calm, curious, defensive, hunting
- **Scale references**: Close-ups, medium shots, full body

**Prompting Template:**
```
Photorealistic [Pokémon name], [pose/action], [angle], wildlife photography style,
natural lighting, [environment hints], BBC Earth documentary quality,
shot on RED camera, 8K detail, shallow depth of field
```

### 2. Environment Assets (8-10 images)

Create atmospheric backgrounds for each scene type:
- **Primary habitat**: Main location where story takes place
- **Secondary locations**: Supporting environments
- **Time variations**: Dawn, day, dusk, night versions
- **Weather moods**: Clear, misty, stormy

**Prompting Template:**
```
Photorealistic [environment type], [time of day], [weather/atmosphere],
National Geographic photography, cinematic composition,
volumetric lighting, no people, pristine wilderness, 8K resolution
```

### 3. Props & Elements (4-5 images)

Create supporting visual elements:
- **Interactive objects**: Prey, food sources, nesting materials
- **Atmospheric effects**: Mist, particles, light rays
- **Environmental details**: Rocks, plants, water features

## Generation Process

### Step 1: Asset Planning

Create a detailed asset list based on the chosen story script:

```markdown

...

### Environment Assets
1. [Description] - for Segments [X, Y, Z]
...

### Props & Elements
1. [Description] - for Segments [X, Y, Z]
...
```

### Step 2: Asset Generation

Use the generation script for each asset:

```bash
python scripts/generate_asset.py \
  --name "[asset_name]" \
  --prompt "[detailed prompt]" \
  --output "[pokemon]/assets/[filename].png"
```

### Step 3: Quality Verification

Check each generated asset for:
- ✅ Photorealistic quality (no obvious AI artifacts)
- ✅ Correct subject/composition
- ✅ Appropriate resolution (minimum 1920x1080)
- ✅ Usable for compositing (clean edges, good lighting)

## Prompting Best Practices

### Do's:
- Start with "Photorealistic" for consistent style
- Include specific lighting direction
- Reference professional photography styles
- Specify camera/lens characteristics
- Add "8K", "high detail", "sharp focus"

### Don'ts:
- Avoid "cartoon", "anime", "illustration"
- Don't include text or watermarks
- Avoid human elements
- Don't specify exact pixel dimensions in prompt
